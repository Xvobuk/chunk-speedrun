# Облачный приёмник

Рабочий адрес: https://chunkspeedrun-receiver.xvobuk.workers.dev

Cloudflare Workers Free, без собственной базы. GET `/health` проверяет наличие настройки; POST `/results` принимает результат без входа игрока и создаёт Issue в фиксированном репозитории Xvobuk/chunk-speedrun. GitHub Actions публикует таблицы. Наличие секрета в health ещё не гарантирует действительность ключа.

Ключ хранится только в Cloudflare Settings → Runtime variables and secrets → Production → `GITHUB_TOKEN` (Secret). Созданный ключ действует до **30 января 2027**. При замене создать fine-grained PAT: только chunk-speedrun, Issues read/write, Metadata read-only; вставить в Secret и развернуть. Не сохранять ключ в мод, GitHub, `.env` в репозитории или чат.

Для повторного развёртывания: загрузить worker.mjs в редактор Cloudflare и Deploy; сохранить существующий Secret. wrangler.jsonc — конфигурация для альтернативного развёртывания официальным Wrangler. Рабочее развёртывание выполнено через панель, журналы вызовов включены в панели. Исходник не журналирует тело заявки и IP. Конфигурация Wrangler отключает observability по умолчанию.

Проверка исходника: `node --test cloudflare/test-worker.mjs` из корня проекта (Node 22+).

Ограничения: тело до 4096 байт, ник 3–16 ASCII символов, корректные времена и версия правил. Примерно 30 запросов/IP/час и 240/час на экземпляр Worker; ограничения в памяти и не являются глобальной защитой от спама. Повторные ID проверяются по records.json и 100 последним Issues. При одновременных запросах в разных экземплярах возможны дубли Issues, итоговая таблица объединяет их по ID. Клиентские подтверждения игнорируются, подтверждение возможно только через moderation.json.

Бесплатный тариф имеет квоты Cloudflare. При недоступности GitHub, истечении ключа или превышении квот мод сохраняет результат локально и повторяет отправку. Не обещается бесперебойная доступность. Старый туннель не должен заменять постоянный адрес: поле hosting в submission-endpoint.json защищает от этого.
